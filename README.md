# QUE APRENDI DEL CURSO DE GIT Y GITHUB


##### QUE ES GIT? 
Es un software que fue creado por el creador de linux, que sirve para guardar la versiones de cada proyecto que se haga va almacenando los cambios que pueda tener esos archivos, a esos cambios que teine un archivo se les conoce como commits.

##### QUE ES UN COMMIT?
El commit es todo cambio que se le hace a un repositorio, a cada persona se le da una copia del archivo y cada persona hace y guarda sus commits en el repositorio, una vez teniendo ya los comitts se guardan en el repositorio local.

##### QUE ES UNA RAMA?
Una rama en Git es una linea donde se puede trabajar en equipo con los commits sin afectar el codigo principal, es  un ambiente donde se puede trabajar con el codigo poniendole mas funciones y demas cosas<  m >
##### QUE ES UN REPOSITORIO? 
un repositorio (comúnmente llamado "repo") es, en esencia, un lugar donde se almacenan los archivos de un proyecto digital.
es como un molde donde se pueden almacenar datos codigos fuente y archivos de investigación 

### QUE COMANDOS APRENDI 

- git init
Inicializa y crea un repositorio en Git

- git clone 
se utiliza para descargar una copia de un repositorio nuevo

- git commit -m 
confirma los cambios que ya estan hechos y listos para subir al repositorio local

- git push u origin main 
sube los commits locales al repositorio remoto de GIT hub
